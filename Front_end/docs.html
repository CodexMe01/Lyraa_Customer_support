Lyraa Agent — Developer Guide

Lyraa is an open-source, RAG-powered customer support agent. It combines a FastAPI backend, a Pinecone vector store, Groq LLM inference, and an MCP server — so any AI coding assistant can query it as a tool.

ℹ️
Before you start You need Python 3.10+, uv (recommended) or pip, and API keys for Groq, Pinecone, Cohere, and Google Gemini. All keys have free tiers.

📦 Installation

Clone the public repository from GitHub and install the dependencies. The project uses uv for fast, reproducible installs — but plain pip works too.

1

Clone the repository

bash
git clone https://github.com/<your-org>/Lyraa_agent.git
cd Lyraa_agent
2

Install dependencies

Primary method using uv (recommended):

bash — uv (recommended)
# Install uv if you don't have it
pip install uv

# Sync all dependencies from uv.lock (exact versions)
uv sync

# Activate the virtual environment
.venv\Scripts\activate    # Windows
source .venv/bin/activate  # macOS / Linux

Alternative using pip:

bash — pip (alternative)
python -m venv .venv
.venv\Scripts\activate     # Windows
source .venv/bin/activate   # macOS / Linux

pip install -r Back_end/requirements.txt
3

Create your .env file

Copy the example and fill in your API keys (see Environment Variables below).

bash
cp .env.example .env
# Then edit .env with your credentials

▶️ Running the Server

Start the FastAPI backend from inside the Back_end folder.

bash
cd Back_end
uvicorn app.main:app --reload --port 8000

The API is at http://localhost:8000 and interactive docs at http://localhost:8000/docs.

✅
Health check GET /health returns {"status":"healthy"} when the server is ready.

🔌 What is the MCP Server?

The Model Context Protocol (MCP) server exposes Lyraa's customer support agent as a tool that any MCP-compatible AI client can call directly. Instead of using the REST API, your AI assistant calls ask_support_agent(query) and gets a grounded RAG response.

python — Back_end/Mcp_server/server.py
from fastmcp import FastMCP
from agent.bot import chat_with_agent

mcp = FastMCP("LyraaSupportServer")

@mcp.tool()
def ask_support_agent(query: str) -> str:
    """Ask the RAG-powered customer support agent a question."""
    result = chat_with_agent(query)
    return result["response"]

⚙️ Connect to a Client

Option A — Auto-install via CLI

bash — automatic
# From the project root (virtual env must be active)
uv run mcp install Back_end/Mcp_server/server.py --name LyraaSupportServer

Option B — Manual JSON (recommended for reliability)

ClientConfig File Path
Claude Desktop (Windows)%APPDATA%\Claude\claude_desktop_config.json
Claude Desktop (macOS)~/Library/Application Support/Claude/claude_desktop_config.json
OpenCode~/.config/opencode/config.json
Gemini CLI~/.gemini/config.json

Add this block (with your actual path) inside mcpServers:

json — Windows virtual env path
{
  "mcpServers": {
    "LyraaSupportServer": {
      "command": "C:\\path\\to\\Lyraa_agent\\.venv\\Scripts\\python.exe",
      "args": [
        "C:\\path\\to\\Lyraa_agent\\Back_end\\Mcp_server\\server.py"
      ]
    }
  }
}
⚠️
Restart the client after editing the config — Changes only take effect after fully quitting and relaunching your AI client.

💬 Chat Endpoints

Base URL: http://localhost:8000. All routes are prefixed with /api.

MethodEndpointDescription
POST/api/chatSend a message. Returns response + intent classification.
POST/api/chat/streamStreaming SSE endpoint. Yields {"token":"…","intent":"…","done":bool} events.
GET/healthHealth check. Returns {"status":"healthy"}.

Example request

bash — cURL
curl -X POST http://localhost:8000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "What is your return policy?", "user_id": "user-1"}'

📄 Document Endpoints

MethodEndpointDescription
POST/api/uploadUpload a file (PDF, DOCX, TXT, CSV, image) to Cloudinary. Auto-expires after 24 h.
GET/api/documents?user_id=…List all cloud-stored files for a user.
GET/api/documents/download?public_id=…Download a file from Cloudinary by its public ID.
DELETE/api/documents?public_id=…Delete a file from Cloudinary.
POST/api/add-linkScrape a URL via Tavily and stage its content for ingestion.

🗄️ Ingestion & Maintenance

MethodEndpointDescription
POST/api/ingestRun the RAG pipeline — indexes staged documents into Pinecone. Modes: all or recent.
POST/api/cleanupManually trigger 24-hour file expiry cleanup (also runs hourly automatically).

Document workflow

1

Upload a knowledge document

bash
curl -X POST http://localhost:8000/api/upload \
  -F "file=@refund_policy.pdf" \
  -F "user_id=admin"
2

Index it into Pinecone

bash
curl -X POST http://localhost:8000/api/ingest \
  -H "Content-Type: application/json" \
  -d '{"mode":"recent","user_id":"admin"}'
3

Query — the agent now knows your document

bash
curl -X POST http://localhost:8000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message":"What is the refund policy?","user_id":"user-1"}'

🛠️ Troubleshooting

ModuleNotFoundError: No module named 'llama_index'

❌
The MCP server is running with a Python interpreter that doesn't have the project dependencies installed. Always point the client config to your virtual environment's Python executable.
json — correct venv path (Windows)
"command": "C:\\path\\to\\Lyraa_agent\\.venv\\Scripts\\python.exe"

ImportError: cannot import name 'McpError' / 'FastMCP'

⚠️
Version mismatch between fastmcp and mcp. Run uv sync --reinstall to restore locked versions.

Server not appearing in AI client

  1. Verify the JSON config has no trailing commas.
  2. On Windows, use double backslashes in paths (\\).
  3. Fully quit and relaunch the AI client after saving config.
  4. Test manually: python Back_end/Mcp_server/server.py — should print "Starting Lyraa MCP Server…" with no errors.

Pinecone errors on startup

Verify PINECONE_INDEX_NAME matches an existing index in your Pinecone project and PINECONE_ENV matches your region.
